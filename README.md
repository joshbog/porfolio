# Joshua Nwabogor — Portfolio

Product design and engineering case studies, laid out as a retro broadsheet.

A single static page (`index.html`) with hash-based navigation, plus optimised images in `img/`. No build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Deploy

Any static host works (GitHub Pages, Netlify, Vercel). For GitHub Pages: Settings → Pages → deploy from the `main` branch, root folder.

## Pages

- `#work` — front page
- `#cro`, `#rebrand`, `#sameday`, `#uba`, `#oasis`, `#easycoop` — case studies
- `#process`, `#about`, `#contact`
